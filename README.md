# EduPlatform — نسخة GitHub Pages تجريبية

موقع عربي متجاوب لإدارة سجلات الطلاب والمدرسين والمقررات والحضور والأقساط والإعلانات، مع لوحة إحصائيات. البيانات تحفظ في localStorage على جهاز المستخدم فقط؛ لا توجد حسابات فعلية أو خادم أو قاعدة بيانات مشتركة.

## النشر
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملف `index.html` إلى جذر المستودع (وملف README اختياريًا).
3. افتح Settings → Pages، واختر Deploy from a branch، ثم `main` و`/(root)`، واحفظ.
4. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في Pages.

**لا تدخل بيانات شخصية حقيقية أو معلومات مالية حساسة في هذه النسخة التجريبية.** للاستخدام الفعلي بين أجهزة متعددة يلزم خادم وقاعدة بيانات وصلاحيات وتسجيل دخول آمن ونسخ احتياطي.
